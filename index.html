vmpx-expanded

Fork of skyboundfs/vmpx · Rust workspace, edition 2024, MIT · fully static analysis.

About

vmpx-expanded is a fork of github.com/skyboundfs/vmpx, a Rust toolkit for the static devirtualization of VMProtect-protected Windows PE files. It parses and symbolically analyzes the target; nothing is ever executed. The goal is clean, behavior-preserving devirtualized output, reached as provable milestones.

Summary

The toolkit chains unpacking, protector detection, VM entry discovery and handler analysis, symbolic lifting, native code generation, and PE reconstruction behind a single proof-gated vmpx clean command. Its recurring design rule is to fail closed: ambiguity is recorded in a report and yields no output rather than a guess. The upstream code was inspected statically and found to contain no malware. In this fork the work is organized as a roadmap of sub-projects; SP1 (native reintegration and image emission, behind an explicit --experimental mode) is in progress. For a protected input, clean still reports blockers and does not emit a devirtualized file by default.
